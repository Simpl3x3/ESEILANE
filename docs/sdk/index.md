# Client SDKs

ESEILANE provides official client libraries for the most popular languages.

| SDK | Language | Install | Status |
|---|---|---|---|
| [eseilane](sdk/python) | Python 3.11+ | `pip install eseilane` | Stable |
| [eseilane-js](sdk/typescript) | TypeScript / Node.js 20+ | `npm install eseilane-js` | Stable |
| eseilane-go | Go 1.22+ | `go get github.com/Simpl3x3/eseilane-go` | Coming Q3 2026 |
| eseilane-java | Java 17+ | Maven / Gradle | Coming Q3 2026 |
| eseilane-rust | Rust 1.80+ | `cargo add eseilane` | Coming Q4 2026 |

---

Community SDKs and integrations are listed in the [Awesome ESEILANE](https://github.com/Simpl3x3/ESEILANE/discussions) discussion.
